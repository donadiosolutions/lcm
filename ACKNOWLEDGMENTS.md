# Acknowledgments

Long Context Manager (LCM) builds on prior open-source work and research.

## Parent repository

This repository was cloned from
[`lossless-claude/lcm`](https://github.com/lossless-claude/lcm). We acknowledge
Pedro Almeida and the repository's prior contributors for the work carried
forward into this project.

## Original implementation

The parent project was based on
[`Martian-Engineering/lossless-claw`](https://github.com/Martian-Engineering/lossless-claw),
the original lossless-claw implementation by Martian Engineering.

## Research foundation

The underlying Lossless Context Management approach was introduced in
Voltropy's paper
[*LCM: Lossless Context Management*](https://papers.voltropy.com/LCM). The paper
is also available from [arXiv](https://arxiv.org/abs/2605.04050).
